# Video Creator Toolkit

A practical, community-friendly collection of workflows, checklists, and reusable planning templates for independent video editors and content creators.

This project focuses on clear, repeatable workflows for short-form video production, motion graphics, client communication, and AI-assisted pre-production.

## What's included

- `guides/premiere-project-organization.md` — a clean folder and project organization workflow.
- `guides/social-video-export-checklist.md` — a pre-export checklist for vertical social videos.
- `guides/after-effects-render-checklist.md` — a practical render and handoff checklist.
- `guides/ai-video-prompt-template.md` — a structured template for writing more controllable AI video prompts.
- `templates/client-video-brief.md` — a client intake brief.
- `templates/reel-planning-sheet.md` — a simple reel planning worksheet.

## Who this is for

Freelance video editors, small creative teams, social media creators, and students learning post-production.

## How to use

Read the guides, copy the templates, and adapt them to your own workflow. If you find an error or have a useful improvement, open an issue or submit a pull request.

## Project status

This is an early community resource. It is intentionally practical and lightweight. Contributions, corrections, and tested workflow examples are welcome.
