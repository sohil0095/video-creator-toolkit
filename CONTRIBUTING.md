# Contributing

Thanks for considering a contribution.

## Useful contributions

- Correcting unclear or inaccurate instructions.
- Adding a workflow that you have personally tested.
- Improving accessibility and readability.
- Adding examples for different editing tools or delivery platforms.
- Translating a guide while preserving its meaning.

## Before submitting

1. Read the relevant guide from beginning to end.
2. Test technical settings in your own software/version before presenting them as universal.
3. Clearly label software-version-specific advice.
4. Do not include client footage, private information, paid assets, or copyrighted material you do not have permission to share.
5. Explain what you changed and why.

## Pull requests

Keep changes focused. Include the software version and test context when relevant. Be respectful and constructive in reviews.
