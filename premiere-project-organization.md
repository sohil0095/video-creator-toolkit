# Organizing a Premiere Pro Project

A consistent folder structure makes projects easier to reopen, hand off, archive, and troubleshoot.

## Suggested folder structure

```text
Project_Name/
├── 01_Project_File/
├── 02_Footage/
│   ├── A-Roll/
│   ├── B-Roll/
│   └── Screen_Recordings/
├── 03_Audio/
│   ├── Voiceover/
│   ├── Music/
│   └── SFX/
├── 04_Graphics/
│   ├── Logos/
│   ├── Stills/
│   └── Overlays/
├── 05_Exports/
│   ├── Review/
│   └── Final/
└── 06_Assets_and_Notes/
```

## Practical habits

1. Create the folders before importing media.
2. Use descriptive names for sequences, such as `ClientName_Reel_9x16_v01`.
3. Keep review exports separate from final deliveries.
4. Use proxies when source media is difficult to edit smoothly.
5. Keep project files and linked media together when archiving.
6. Before moving a project to another computer, use Premiere Pro's project collection tools and verify that media is available.

## Handoff checklist

- [ ] Project opens without missing-media warnings.
- [ ] Final sequence is clearly named.
- [ ] Required fonts, graphics, and licensed assets are accounted for.
- [ ] Final export is in the correct folder.
- [ ] Review files are not confused with final files.

This is a suggested workflow, not a mandatory Adobe folder structure.
